# To-Do List 📝

A professional, responsive, and bilingual To-Do List built with HTML, CSS, and JavaScript.

## Features

- 🇬🇧 English and 🇮🇷 Persian language support
- 🌙 Dark / Light mode
- 📱 Responsive design
- ➕ Add tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🧹 Clear all tasks
- 📊 Total / completed / pending task counters
- 💾 Tasks, language, and theme saved with LocalStorage
- 🚫 Empty-task validation

## Technologies

- HTML5
- CSS3
- JavaScript
- DOM
- LocalStorage

## Run locally

Open `index.html` in your browser.

## Live Demo

After publishing with GitHub Pages, the project can be opened from the repository's `todo-list/` path.
