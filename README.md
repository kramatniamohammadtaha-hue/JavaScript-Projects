### 🧮 BMI Calculator

A professional, responsive, and bilingual BMI Calculator built with HTML, CSS, and JavaScript.

**Features:**

* 🇬🇧 English and 🇮🇷 Persian language support
* 🌙 Dark / Light mode
* 📱 Fully responsive design
* 📊 BMI category detection
* ✅ Input validation
* 🔄 Reset functionality
* 💾 Language and theme preferences saved with LocalStorage
* 🎨 Modern and clean user interface

**Technologies:**

* HTML5
* CSS3
* JavaScript
* DOM
* LocalStorage
