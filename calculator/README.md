# Calculator 🧮

A professional, responsive, and bilingual calculator built with HTML, CSS, and JavaScript.

## Features

- 🇬🇧 English and 🇮🇷 Persian language support
- 🌙 Dark / Light mode
- 📱 Responsive design
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ✅ Input validation
- 🚫 Division-by-zero protection
- 🔄 Reset functionality
- 💾 Language and theme preferences saved with LocalStorage

## Technologies

- HTML5
- CSS3
- JavaScript
- DOM
- LocalStorage

## Run locally

Open `index.html` in your browser.

## Live Demo

After publishing this repository with GitHub Pages, the project can be opened from its `calculator/` path.
