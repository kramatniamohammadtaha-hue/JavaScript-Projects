# Weather App 🌦️

A professional, responsive, and bilingual Weather App built with HTML, CSS, and JavaScript.

## Features

- 🌦️ Search weather by city
- 🌡️ Current temperature
- 💧 Humidity
- 💨 Wind speed
- 🌡️ Feels-like temperature
- ☀️ Weather condition and icon
- 🇬🇧 English and 🇮🇷 Persian language support
- 🌙 Dark / Light mode
- 📱 Responsive design
- 🌐 Real weather data using Open-Meteo APIs
- 🚫 Input validation and error handling
- 💾 LocalStorage for language and theme preferences

## Technologies

- HTML5
- CSS3
- JavaScript
- DOM
- Fetch API
- Async / Await
- JSON
- REST APIs
- LocalStorage

## API

This project uses Open-Meteo for geocoding and weather data.

No API key is required.

## Run locally

Open `index.html` in a modern browser with an internet connection.
