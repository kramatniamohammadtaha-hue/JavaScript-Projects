# BMI Calculator

A modern, responsive and bilingual BMI (Body Mass Index) calculator built with **HTML, CSS and Vanilla JavaScript**.

## ✨ Features

- 🇮🇷 Persian / 🇬🇧 English language switch
- RTL / LTR layout switching
- Language preference saved with LocalStorage
- 🌙 Dark / Light mode
- BMI calculation
- BMI category detection
- Interactive BMI range indicator
- Form validation
- Reset button
- Responsive design for mobile, tablet and desktop
- Clean separated HTML, CSS and JavaScript
- No framework or build tool required

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## 📁 Project Structure

```text
bmi-calculator/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
```

## 🚀 Run

No installation is required.

Open `index.html` directly in your browser.

## 🌐 Language

The default language is **English**. Use the **FA** button in the top-right area to switch to Persian.

The selected language is stored in LocalStorage.

## 📌 Note

BMI is a general screening measure and is not a medical diagnosis.
